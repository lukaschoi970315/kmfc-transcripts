1. GitHub 저장소에 새 강의 추가하기

  1. data/lectures/ 폴더에 새 강의 파일(예: vol1-04-next.json, videoId 포함)을 추가합니다.
  2. python3 scripts/sync_transcripts.py를 실행하면 data/catalog.json, 통합 검색 색인, transcripts/*.md 파일이 자동으로 갱신됩니다.
  3. GitHub에 푸시하면 GitHub Pages 사이트에 영상 플레이어와 함께 즉시 반영됩니다.

2. 브라우저에서 JSON 파일 바로 미리보기

파일을 커밋하기 전에 아래에 .json 녹취 파일을 선택하면 이 화면에서 즉시 서식과 목차를 테스트할 수 있습니다.
