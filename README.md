# 근의학 강의 녹취 아카이브 (KMFC Transcript Archive)

**바른몸애 & 한국 근의학 연구소** 강의 동영상 녹취록을 시리즈별 · 주제별 · 핵심 용어별로 체계적으로 정리하고 검색할 수 있는 정적 웹 아카이브입니다.

## 주요 기능

- **시리즈 및 회차 탐색**: 좌측 사이드바에서 강의 시리즈(`최신근육학총설 1권` 등)와 각 회차를 한눈에 탐색하고 학습 완료 여부를 기록합니다.
- **통합 전문 검색 (`/` 또는 `⌘K`)**: 모든 강의의 제목, 핵심 용어, 녹취 본문 전체를 즉시 검색하고 해당 시점으로 바로 이동합니다.
- **핵심 요약 & 용어 색인**: 각 강의별 요약·핵심 학습 포인트·해부학/근의학 용어 해설을 탭으로 분리해 제공하며, **전체 강의 통합 용어 색인**도 지원합니다.
- **읽기 친화적 뷰**: 라이트/다크 테마, 고딕/명조 전환, 글자 크기 3단계, 시간 표시 토글, 개인 학습 메모(브라우저 로컬 저장), 마크다운 복사/`.md` 저장/인쇄(PDF) 지원.

## 새 녹취본 추가 방법

1. `data/lectures/` 아래에 새 강의 JSON 파일(예: `vol1-02-trapezius.json`)을 추가합니다.
2. 아래 명령을 실행하면 `data/catalog.json`과 `transcripts/*.md` 파일이 자동으로 생성·갱신됩니다.

```bash
python3 scripts/sync_transcripts.py
```

3. 변경 사항을 GitHub에 커밋하고 푸시하면 사이트에 즉시 반영됩니다.

## 디렉터리 구조

```text
├── index.html                   # 메인 웹 앱
├── styles/main.css              # 라이트/다크 테마 및 반응형 스타일
├── js/app.js                    # 아카이브 탐색, 검색, 용어 색인, 내보내기 로직
├── data/
│   ├── catalog.json             # 시리즈 및 강의 목록 인덱스
│   └── lectures/*.json          # 강의별 구조화 녹취 데이터
├── transcripts/*.md             # GitHub에서 바로 읽을 수 있는 마크다운 녹취본
└── scripts/sync_transcripts.py  # catalog.json 및 Markdown 자동 동기화 스크립트
```
